# ЧИСТЮЛЯ — сайт клининговой службы (Барановичи)

Полноценный демо-проект сайта клининговой службы с **живым сценарием заявки**:

```
клиент выбирает услуги → видит цену → прикрепляет фото → оставляет заявку
        ↓
оператор видит заявку в кабинете → ставит статус, отвечает, выдаёт скидку
        ↓
клиент в это время играет в мини-игру и получает скидку на заказ
```

Белый + небесно-голубой, **без фреймворков, без сборки, без платных сервисов**.
Всё работает из обычных HTML/CSS/JS — задеплоить можно за 5 минут.

## 🎬 Сценарий показа заказчику (5 минут)

1. **Главная** — листайте сайт, покажите 17 услуг с ценами и слайдер «до/после»
   (подписи «ДО» и «ПОСЛЕ» привязаны к ползунку — потяните его).
2. **Выберите 2–3 услуги** → справа снизу всплывёт корзина со стоимостью.
3. **«Вызвать клининг»** → заполните имя и телефон → прикрепите фото →
   выберите способ связи → **«Отправить заявку»**.
4. **Страница подтверждения**: сверка услуг, итоговая сумма и кнопка
   **«Почистить мебель»** — открывает окно с тремя играми.
5. **Запустите игру** — выберите комнату, берите нужный инструмент.
   Неверный инструмент → подсказка «Для такой грязи нужна губка».
6. **Войдите как оператор** — иконка замка в левом нижнем углу (или ссылка
   «Вход для персонала» в подвале). PIN: **1432** (подсказка есть в окне).
7. **Кабинет оператора**: заявка уже там — имя, телефон, услуги, сумма, фото.
   Поставьте статус «В работе», напишите ответ → он появится у клиента.
8. **Вернитесь на главную** → раздел «Мои заявки» → введите номер →
   видно заявку, статус и бонусы.

## 🎮 Мини-игры

Три игры на Canvas 2D. В каждой — **своя комната и свой набор грязи**.
Пять средств чистки, девять видов грязи, неверный инструмент → понятная подсказка.

| Игра | Что убирать | Чем |
|---|---|---|
| Пропылесось ковёр | Пыль, шерсть, крошки | Пылесос · Пылесос · Веник |
| Отмой диван | Жирное пятно, старое пятно, разводы воды | Губка · Щётка · Тряпка |
| Отдери подпалины | Подпалина, засохший клей, пыль в щелях | Щётка · Тряпка · Пылесос |

**Связка «грязь → инструмент»:**

| Грязь | Инструмент |
|---|---|
| Пыль, шерсть, пыль в щелях | Пылесос |
| Жирное пятно | Губка |
| Старое пятно, подпалина | Щётка |
| Разводы воды, засохший клей | Тряпка (нужно **протереть** — водить по пятну) |
| Крошки и мусор | Веник |

Внизу игры всегда висит легенда «Чем чистить: …» — чтобы игрок не гадал.
Таймер 60 секунд, прогресс-бар, счётчик «Осталось: N», частицы и всплывающие подписи.

**Правила:**
- одна игра на один заказ — второй раз не даётся;
- при правке заявки игра не перезапускается (иначе можно было бы выиграть бесконечно скидок);
- при смене номера старая заявка **архивируется** («ЗАМЕНЕНА»), а не удаляется.

## 🎁 Как применяется скидка

Клиенту **ничего вводить не нужно**, оператору — тоже:

- приз «на текущий заказ» → скидка сразу уменьшает итог, оператор видит её в кабинете;
- приз «на следующий заказ» → скидка закрепляется за номером телефона;
- **если у клиента накопилось несколько скидок — применяется максимальная**,
  остальные автоматически помечаются заменёнными («заменена на «Скидка 20%…»»);
- в карточке заявки в админке есть блок **«БОНУС КЛИЕНТА»** — оператор видит,
  какая скидка сработает в следующий раз и ничего не нажимает.

Клиенту ничего вводить не нужно: скидка применится сама.

> Кнопки «выбрать скидку» в админке нет намеренно — она только путала.
> Все скидки выдаёт мини-игра, а дальше всё происходит автоматически.

### Приём заявок (главное для боевого запуска)

Сейчас заявки лежат в `localStorage` браузера. Чтобы оператор получал их
на другом устройстве — включите **один** из двух каналов (можно оба):

**А. Telegram-бот (бесплатно, без карты)** — заявка падает в чат/канал:
1. @BotFather → `/newbot` → получите токен (вида `123456:ABC-…`)
2. Создайте группу, добавьте бота, узнайте `chat_id` (через @userinfobot)
3. Впишите в `config.js`:
   ```javascript
   TG_BOT_TOKEN: '123456:ABC-…',
   TG_CHAT_ID:   '-1001234567890',
   ```
4. Фото клиента отправляется в Telegram отдельной картинкой с подписью.

**Б. Готовый сервис форм (бесплатно, без карты)**:
```javascript
FORM_ENDPOINT: 'https://formspree.io/f/ВАШ_ID'      // до 50 заявок/мес
// или
FORM_ENDPOINT: 'https://api.web3forms.com/submit'   // безлимитно
```

> Пока оба канала не настроены — заявки работают только в этом браузере.
> Это нормально для показа, но **не для боевого запуска**.

## ☁️ Публикация

### Cloudflare Pages (рекомендуется)

**Вариант А — без git и командной строки (самый простой):**

1. Зайдите на **dash.cloudflare.com** → зарегистрируйтесь (email + пароль, карта не нужна).
2. Слева **Workers & Pages** → **Create** → вкладка **Pages** → **Upload assets** («Загрузить файлы»).
3. Имя проекта: `chistulya` (получите адрес `chistulya.pages.dev`).
4. Перетащите **всё содержимое папки проекта** (не саму папку!) в окно загрузки.
5. **Deploy site**. Через минуту сайт доступен по адресу `chistulya.pages.dev`.

Обновления: тот же экран → **Create new deployment** → снова перетащите файлы.

**Вариант Б — через git (удобно для автообновлений):**

1. Залейте папку в git-репозиторий (GitHub / GitLab).
2. Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git**.
3. Выберите репозиторий, root directory — `.` (или корень проекта).
4. Build command — **пусто**, output directory — **пусто** (или `.`).
5. Деплой. Получите адрес вида `chistulya.pages.dev`.
6. Свой домен: Pages → Custom domains → добавьте `chistulya.by`.
   Файл `CNAME.example` → переименуйте в `CNAME` и впишите свой домен.

**Почему Cloudflare Pages:**
- бесплатно **без привязки карты** и **без срока годности** — лежит годами, пока не удалите;
- **безлимитный трафик** (сайт не «умрёт» от популярности);
- 500 деплоев в месяц, 20 000 файлов, файл до 25 МБ — нашему сайту нужно ~20 файлов;
- `_headers` подхватывается автоматически (кэш статики на год, HTML без кэша);
- передача прав клиенту: переносите репозиторий (вариант Б) в его аккаунт Cloudflare — он платит.

### Другие бесплатные варианты (тоже без карты)

| Вариант | Цена | Как передать клиенту |
|---|---|---|
| Cloudflare Pro / Business | $20–200/мес | Проект переносится в аккаунт клиента |
| Vercel Pro | $20/мес на пользователя | Перенос команды |
| Netlify | $19+/мес | Перенос проекта |
| VPS (Hetzner, Timeweb) | €4–8/мес | Передаёте доступ к серверу — платит напрямую |

**Схема перехода:**
```
показ брату        → Cloudflare Pages (бесплатно, без карты)
первые клиенты     → тот же Cloudflare Pages, репозиторий переносится клиенту
появился доход      → VPS или Cloudflare Pro на карте клиента
```
